# Структура программы робота

- `Nodes/` — команды, дерево программы, ветвления и условия. Реализация собрана в `RobotProgrammObject.cs`; одноимённые файлы классов регистрируют ресурсы в Godot.
- `Runtime/` — контекст одного запуска и интерфейс движения `IRobotMotion`.
- `Variables/` — менеджер и ресурсы переменных.
- `ProgramCommandAttribute` и `ProgramCommandRegistry` — каталог команд редактора.

Чтобы добавить команду, унаследуй её от `NodeBase`, пометь `[ProgramCommand("Название")]` и опиши параметры через `[Export]`. Редактор автоматически добавит её в подходящие меню и построит поля параметров. Для сохранения команды как Godot Resource добавь в `Nodes/` одноимённый partial-класс с `[GlobalClass]`.
